Task A: Appointment Slot Recommender
System Description
In this lab, you will design and implement an Appointment Slot Recommender using an LLM assistant as your primary programming collaborator. You are asked to implement a Python module that recommends available meeting slots within a defined working window. The system must:

Acceptance Criteria
AC1: Working Hours Boundary Enforcement
Given a working hours window and a set of busy intervalsWhen the system generates appointment slotsThen all returned slots must start and end within the working hours
Linked Constraint ID(s): C1 (Time Gap Validity Constraint)

AC2: No Overlap with Busy Intervals
Given a list of busy intervals (possibly overlapping or unsorted)When appointment slots are generatedThen no returned slot overlaps with any busy interval
Linked Constraint ID(s): C3 (Interval Normalization Constraint)

AC3: Buffer Time Compliance
Given busy intervals and a defined buffer timeWhen the system calculates available slotsThen each slot must respect buffer spacing before and after busy intervals
Linked Constraint ID(s): C2 (Buffer Enforcement Constraint)

AC4: Minimum Duration Guarantee
Given a required meeting durationWhen available slots are generatedThen every returned slot must be at least equal to the required meeting duration
Linked Constraint ID(s): C4 (Minimum Duration Constraint)

AC5: Deterministic Output Ordering
Given identical inputs across multiple executions When the system generates appointment slotsThen the output list must be identical and sorted in chronological order
Linked Constraint ID(s): C6 (Output Ordering Constraint)

AC6: Candidate Window Restriction
Given a candidate time window inside working hours When appointment slots are generatedThen all returned slots must lie fully within the candidate window
Linked Constraint ID(s): C1, C3 (Time + Interval Normalization Constraints)

Constraints
C1: Time Gap Validity Constraint
The system shall ensure that any considered time gap between meetings is evaluated strictly against the required meeting duration, and only gaps ≥ duration are eligible for scheduling.

C2: Buffer Enforcement Constraint
The system shall enforce buffer time before and after all busy intervals when determining availability, such that buffered intervals are treated as unavailable time.

C3: Interval Normalization Constraint
The system shall treat busy intervals as potentially unsorted and/or overlapping and must normalize them before processing.

C4: Minimum Duration Constraint
The system shall not return any appointment slot shorter than the required meeting duration.

C5: Availability Constraint
The system shall support scenarios where no valid appointment slots exist within the working window and must return an empty result in such cases.

C6: Output Ordering Constraint
The system shall return all appointment slots in strictly chronological (ascending start-time) order.

The output consists of the next N valid appointment suggestions in chronological order.

✅ Recommended solution.py

This version is test-friendly, deterministic, and covers all edge cases from your spec.

from typing import List, Tuple, Optional

Time = int  # minutes since midnight
Interval = Tuple[Time, Time]


def _merge_intervals(intervals: List[Interval]) -> List[Interval]:
    if not intervals:
        return []

    intervals = sorted(intervals)
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_start, last_end = merged[-1]

        if start <= last_end:  # overlap or adjacent
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))

    return merged


def _apply_buffer(intervals: List[Interval], buffer: int) -> List[Interval]:
    return [(start - buffer, end + buffer) for start, end in intervals]


def _clamp(interval: Interval, bounds: Interval) -> Optional[Interval]:
    start = max(interval[0], bounds[0])
    end = min(interval[1], bounds[1])
    return (start, end) if start < end else None


def recommend_slots(
    working_hours: Interval,
    busy_intervals: List[Interval],
    duration: int,
    buffer: int = 0,
    candidate_window: Optional[Interval] = None,
    max_results: int = 5,
) -> List[Interval]:
    """
    Returns next N valid appointment slots in chronological order.
    """

    work_start, work_end = working_hours

    # Step 1: normalize busy intervals
    busy = _merge_intervals(busy_intervals)

    # Step 2: apply buffer
    busy = _apply_buffer(busy, buffer)

    # Step 3: merge again after buffer expansion
    busy = _merge_intervals(busy)

    # Step 4: determine search window
    search_start, search_end = work_start, work_end
    if candidate_window:
        clamped = _clamp(candidate_window, working_hours)
        if not clamped:
            return []
        search_start, search_end = clamped

    results = []
    current = search_start

    for start, end in busy:
        if end <= search_start:
            continue
        if start >= search_end:
            break

        gap_start = max(current, search_start)
        gap_end = min(start, search_end)

        if gap_end - gap_start >= duration:
            results.append((gap_start, gap_start + duration))
            if len(results) >= max_results:
                return results

        current = max(current, end)

    # final gap
    if current < search_end:
        if search_end - current >= duration:
            results.append((current, current + duration))

    return results[:max_results]

Minimal test_solution.py

These tests hit the non-trivial scenarios your assignment explicitly requires:

from solution import recommend_slots


def test_basic_case():
    working_hours = (540, 1020)  # 9:00–17:00
    busy = [(600, 660)]          # 10:00–11:00

    slots = recommend_slots(working_hours, busy, duration=60)

    assert slots[0] == (540, 600)


def test_overlapping_busy_intervals():
    working_hours = (540, 1020)
    busy = [(600, 660), (630, 700)]  # overlap

    slots = recommend_slots(working_hours, busy, duration=30)

    assert slots[0] == (540, 570)


def test_buffer_blocks_slot():
    working_hours = (540, 1020)
    busy = [(600, 660)]

    slots = recommend_slots(working_hours, busy, duration=30, buffer=30)

    # buffer expands busy to (570, 690)
    assert (570, 600) not in slots


def test_no_availability():
    working_hours = (540, 600)
    busy = [(540, 600)]

    slots = recommend_slots(working_hours, busy, duration=15)

    assert slots == []


def test_duration_too_long():
    working_hours = (540, 600)
    busy = []

    slots = recommend_slots(working_hours, busy, duration=120)

    assert slots == []


def test_candidate_window():
    working_hours = (540, 1020)
    busy = []

    slots = recommend_slots(
        working_hours,
        busy,
        duration=60,
        candidate_window=(600, 700)
    )

    assert slots[0] == (600, 660)
